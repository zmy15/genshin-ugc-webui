## 三、关键结论摘要

### 3.1 能做

```
✅ HTML 解析        ✅ CSS 选择器 / 层叠 / 继承
✅ 盒模型布局        ✅ flex（含 flex-wrap / grow / shrink）
✅ 绝对定位          ✅ 百分比 / em 单位
✅ transform         ✅ transition（映射 game.Tween）
✅ z-index           ✅ :hover / :active
✅ 点击 / 悬停 / 拖拽  ✅ 逐帧循环 + diff 渲染
✅ 动态列表重建      ✅ 控件池复用
```

### 3.2 引擎边界

```
✅ 矩形裁剪 overflow:hidden —— 图片控件 + 矩形图当遮罩
✅ 运行时换图 —— img:SetImage(Enum.ImageSource.StaticReference, ID)
✅ 任意形状裁剪 —— enableMask 按图片 alpha 裁子控件，形状随图变化且不变形
❌ 自定义字体 / 粗体 / 富文本
❌ 圆角 / 边框 / 阴影（6 个候选字段写入全部失败，只能预配图片）
❌ OnUpdate 回调
❌ 自定义字段（控件上无法存状态）
```

### 3.3 最容易踩的三个坑

**① 控件字段按类型封死**

```lua
容器.bgColor = ...    -- 静默失败（字段不存在）
按钮.text = ...       -- 静默失败
```

**② 控件上无法保存自定义字段**

```lua
c.__myField = 123     -- 静默失败，读回 nil
```

只能用外部表或用引擎 API（`GetChildren`）查询。

**③ 坐标系统**

- 引擎：**左下原点，Y 向上**
- HTML：左上原点，Y 向下
- 子控件 `anchoredPosition` 相对**父中心**
- 必须先设父控件尺寸，否则参照系是默认值（80×80 @ 原点）

### 真机联调中修掉的关键 bug

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 按钮不显示 | 预设按钮无视觉字段 | **双层架构**（textbox + button 覆盖） |
| 2 | 点击后界面不变 | `flush()` 重算样式覆盖手改值 | 新增**运行时样式** `_inline` |
| 3 | 越用越卡 | 样式变更触发全量重写 | **按字段**失效缓存（15次→1次） |
| 4 | 文字不更新 | DOM 文本覆盖脚本值 | 新增 `node:setText()` |
| 5 | 动态列表后控件全不可见 | 池中控件取出未 `SetActive(true)` | 复用后重新激活 |
| 6 | 样式表无限增长 | `setHTML` 累加不清 | 重置 + `_extraSheets` |
| 7 | 监听器累积 | 回收时未移除 | `RemoveAllCursorEventListeners` |
| 8 | 每帧重建全部控件 | 预回收对 `flush()` 也生效 | 用 `domChanged` 区分路径 |
| 9 | 控件复用完全失效 | **自定义字段写不进** | 改用 `GetChildren()` 反查 |
| **10** | **文字凭空消失** | 引擎字号自适应（框高/字号 < 1.8 就压没） | 规则化框高，见 §4.4 |
| **11** | **头像变扁椭圆** | `flex-direction:column` 忽略子项 `width` | 布局器尊重显式宽度 |
| **12** | **容器右侧白竖条** | `intrinsicWidth` 重复计算 `margin` | margin 不计入固有宽度 |
| **13** | **圆外暗色月牙** | 裁剪容器填充不受自身遮罩约束 | 裁剪容器不填充 |
| **14** | **裁剪边缘白边** | 遮罩图自身可见（形状图是白色） | 裁剪容器 `imageColor` 置全透明 |

## 五、测试方法学

这些是付出真机轮次代价换来的：

| 原则 | 说明 |
|---|---|
| **探针必须读回实际值** | 只打印"我打算设什么"会误导 |
| **一次只改一个变量** | 否则无法定位 |
| **测试替身必须忠实** | mock 不模拟真机限制 → 全是假阳性 |
| **看数值趋势而非体感** | `created` 持续增长 = 泄漏 |
| **`pairs()` 顺序未定义** | 涉及顺序必须显式排序 |
| **区分客户端/服务端文档** | 官方教程多是服务端悬浮交互页 |

## 六、下一步（可选）

### 可以立即做

1. **做实际界面** —— 库已可用
2. **补图片模板** —— 支持圆角、图标、头像框
3. **性能压测** —— 真机上找控件数拐点

### 可补的功能（见 `GAPS.md`）

| 优先级 | 功能 |
|---|---|
| P1 | `transition` 的 `delay` 补齐、文本精确换行、`text-overflow: ellipsis` |
| P2 | `grid` 布局、`order`、`aspect-ratio` |

### 不建议做

- JS 解释器（无 `coroutine`，性价比极低）
- 完整 CSS 规范（目标是够用）

### 可做但需注意

- **`overflow:hidden` 矩形裁剪** —— 图片控件 + 矩形图当遮罩 + `enableMask`
  （容器**不要**设 `background-color`，底色由内层容器承载）
- **运行时换图** —— `SetImage(Enum.ImageSource.StaticReference, id)`
- **任意形状裁剪** —— 遮罩形状随图片 alpha 变化，等比适配不变形
- **文字框高 ≥ 字号 × 1.9** —— 否则引擎的字号自适应会把字压没
